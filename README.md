Умный телефонный справочник
Язык программирования: C++

🎯 Цель проекта
Разработка консольного приложения для эффективного управления персональной контактной информацией. Программа обеспечивает надёжное хранение данных в оперативной памяти с автоматическим сохранением в файл, включает механизмы валидации ввода, интеллектуальный поиск и сортировку записей.

📦 Описание
Консольное приложение на C++ для работы с базой контактов, содержащей три основных поля: Имя, Телефон и Email. Данные организованы в динамической структуре (std::vector), что позволяет гибко управлять неограниченным количеством записей в пределах доступной оперативной памяти.

✅ Функционал
Интеллектуальное добавление — ввод данных с комплексной валидацией (контроль корректности имени, телефона, email)

Модификация записей — возможность редактирования или удаления любой записи по её индексу в списке

Расширенный поиск — нахождение контактов по частичному совпадению имени (регистронезависимый поиск)

Упорядочивание данных — сортировка списка контактов по алфавиту методом стандартной библиотеки

Персистентное хранение — экспорт и импорт данных в текстовый файл для сохранения между сеансами работы

Защита данных — предотвращение случайного повреждения файлов и проверка целостности при загрузке

Проект организован по модульному принципу:

📱 Интерфейс программы
После запуска отображается главное меню:

=== Умный телефонный справочник ===
1. Показать все контакты
2. Добавить контакт
3. Поиск контакта
4. Редактировать контакты
5. Удалить контакт
6. Сортировать контакты по имени
7. Сохранить в файл
8. Загрузить из файла
0. Выход
Выберите действие:
Основные операции:
Добавить контакт — последовательный ввод имени, телефона и email с автоматической проверкой формата

Показать все контакты — табличное отображение всех записей с форматированием

Поиск по имени — нахождение контактов по части имени (например, "Ив" найдёт "Иван")

Редактировать контакты — выбор записи и модификация отдельных полей или всей информации

Удалить контакт — исключение записи из списка с подтверждением действия

Сортировка по имени — алфавитное упорядочивание контактов (А-Я)

Сохранение в файл — экспорт текущего состояния справочника в файл contacts.txt

Загрузка из файла — восстановление данных из файла contacts.txt

💾 Формат файла данных
Контакты сохраняются в текстовый файл contacts.txt в следующем формате:

Иван Иванов
+7(999)123-45-67
ivan@mail.ru
Петр Петров
89001112233
petrov@gmail.com
Анна Сидорова
8-800-555-35-35
anna.s@company.com
Каждый контакт занимает три строки: имя, телефон, email. При загрузке выполняется проверка корректности данных.

⚙️ Особенности реализации
Валидация данных:
Имя — не может быть пустым, запрещены специальные символы (@#$% и т.д.)

Телефон — проверка по регулярному выражению ^[+]?[0-9\s\-\(\)]{7,15}$

Email — проверка формата user@domain.com через регулярные выражения

Устойчивость к ошибкам:
Обработка некорректного ввода в числовых меню

Защита от повреждения файлов данных

Подтверждение критических операций (удаление)

Автоматическая загрузка данных при старте программы

Производительность:
Использование эффективных алгоритмов стандартной библиотеки

Оптимизированное хранение данных в векторе

Быстрый доступ к элементам по индексу
